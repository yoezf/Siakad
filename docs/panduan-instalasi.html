Hormone Growth

Panduan Instalasi dari GitHub

Pasang proyek di komputer sendiri dan coba dengan data contoh dua sekolah (SD dan SMP).

20 sampai 40 menit PHP 8.3 atau lebih baru Tanpa Node.js MySQL atau MariaDB

Yang perlu disiapkan

GitUntuk mengambil kode. Unduh di git-scm.com. Cek dengan git --version.
PHP 8.3 atau lebih baruEkstensi aktif: gd, intl, mbstring, pdo_mysql, zip, curl, fileinfo, openssl, exif. Cek dengan php -m.
ComposerPengelola pustaka PHP, getcomposer.org. Cek dengan composer --version.
MySQL 8 atau MariaDBDatabase. Contoh: MySQL Installer, XAMPP, atau Laragon.
Akses ke repo. Repo ini privat (github.com/yoezf/Siakad). Minta pemilik menambahkan akun GitHub Anda sebagai kolaborator terlebih dahulu.
Cara termudah di Windows: pasang Laragon atau Laravel Herd. Keduanya sudah membawa PHP dan Composer (Laragon juga MySQL), jadi Anda hanya perlu menambah Git.
1

Ambil kode dari GitHub

Buka terminal (PowerShell atau Command Prompt), pindah ke folder tujuan, lalu:

git clone https://github.com/yoezf/Siakad.git
cd Siakad

Windows akan membuka jendela login GitHub di peramban. Masuk dengan akun yang sudah diberi akses. Bila memakai token, pakai Personal Access Token sebagai kata sandi.

2

Pasang pustaka

composer install

Mengunduh Laravel, Filament, dan pustaka lain serta memasang berkas tampilannya. Butuh beberapa menit. Berhasil bila selesai tanpa tulisan error.

3

Siapkan berkas pengaturan .env

copy .env.example .env
php artisan key:generate

Di macOS atau Linux, ganti copy dengan cp.

4

Buat database

Buka klien MySQL (mysql -u root -p, HeidiSQL, atau phpMyAdmin), lalu jalankan:

CREATE DATABASE sekolah_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'sekolah'@'localhost' IDENTIFIED BY 'GANTI_KATA_SANDI_ANDA';
GRANT ALL PRIVILEGES ON sekolah_app.* TO 'sekolah'@'localhost';
FLUSH PRIVILEGES;

Buka .env dengan editor teks dan samakan baris berikut (hapus tanda # di depan DB_PASSWORD):

DB_DATABASE=sekolah_app
DB_USERNAME=sekolah
DB_PASSWORD=GANTI_KATA_SANDI_ANDA
QUEUE_CONNECTION=sync
QUEUE_CONNECTION=sync membuat analisis AI diproses langsung, tanpa pekerja antrean terpisah. Disarankan untuk uji lokal.
5

Isi data contoh

php artisan demo:isi --ya

Membuat semua tabel dan mengisi SD Harapan Bangsa dan SMP Cendekia Nusantara lengkap dengan siswa, nilai, kehadiran, rapor, dan pengumuman. Sekitar 1 sampai 2 menit.

Awas: perintah ini menghapus seluruh isi database yang dipakai di .env sebelum mengisi ulang. Pakai hanya pada database kosong atau database uji.
6

Jalankan aplikasi

Cara cepat (Windows): klik dua kali jalankan-lokal.bat. Halaman jadi jauh lebih cepat dan unggah foto besar bisa. Cara umum:

php artisan serve

Biarkan terminal terbuka, lalu buka http://127.0.0.1:8000 di peramban.

Yang bisa dicoba

  • Admin SD: dasbor dengan grafik, data master, jadwal, kehadiran, input nilai, rapor, laporan, pengumuman.
  • Wali kelas atau guru: hanya kelas atau mata pelajaran yang diampu.
  • Orang tua dan siswa: nilai, kehadiran, jadwal, rapor, dan pengumuman milik anak sendiri.
  • Super Admin: daftar sekolah dan fitur yang dinyalakan per sekolah.
  • Analisis AI dan Absen wajah hanya muncul di SD, dan mati di SMP (sengaja, untuk menunjukkan kontrol per sekolah).

Opsional: analisis foto dengan AI

Butuh kunci API Gemini milik Anda (Google AI Studio). Tanpa kunci, semua fitur lain tetap jalan.

GEMINI_API_KEY=KUNCI_ANDA
php artisan config:clear
Tulis kunci di .env saja. Jangan di .env.example, jangan dibagikan, dan jangan di-commit. Langkah lengkap ada di PANDUAN-AI.md.

Opsional: absensi wajah dan membuka dari HP

Kamera di peramban hanya aktif lewat localhost atau HTTPS. Di komputer yang sama, buka http://127.0.0.1:8000. Untuk HP di Wi-Fi yang sama, jalankan jalankan-hp-aman.bat, buka alamat https://...:8443 yang ditampilkannya, dan pilih Lanjutkan pada peringatan sertifikat. Detail di PANDUAN-WAJAH.md. Pemuatan pertama mengunduh model wajah sekitar 7 MB.

Masalah yang sering muncul

GejalaPenyelesaian
could not find driverEkstensi pdo_mysql belum aktif. Hapus tanda ; di depan extension=pdo_mysql pada php.ini, lalu mulai ulang terminal.
Access denied for userPengguna atau kata sandi database di .env tidak cocok. Setelah mengubah .env, jalankan php artisan config:clear.
Unknown databaseDatabase belum dibuat (langkah 4) atau namanya beda dengan DB_DATABASE.
Port 8000 dipakaiJalankan php artisan serve --port=8001, lalu buka alamat dengan port itu.
Halaman lambat (sekitar 1 detik per klik)PHP Windows bawaan tanpa OPcache. Pakai jalankan-lokal.bat.
Unggah foto gagalBatas bawaan PHP hanya 2 MB. Pakai jalankan-lokal.bat (batas 12 MB).
AI: cURL error 60Sertifikat SSL PHP belum terpasang. Isi GEMINI_CA_BUNDLE di .env dengan lokasi cacert.pem.
AI tetap "Menunggu"Pastikan QUEUE_CONNECTION=sync, jalankan php artisan config:clear, lalu klik Coba lagi.
Kamera tidak muncul di HPPakai alamat https:// dari jalankan-hp-aman.bat, bukan http://.
Lupa kata sandi atau data berantakanJalankan lagi php artisan demo:isi --ya.
Keamanan. Akun demo memakai kata sandi yang diketahui banyak orang. Jalankan hanya di komputer sendiri atau jaringan tepercaya, jangan di server publik, dan jangan isi data siswa sungguhan. Untuk pemakaian nyata, buat akun dan kata sandi sendiri.

Catatan pengujian

Langkah 1 sampai 6 diuji pada clone baru di Windows 11 dengan PHP 8.4 dan MySQL: pustaka terpasang, demo:isi selesai sekitar 76 detik, dan halaman login Sekolah, Portal, dan Admin menjawab normal. Tampilan setelah login, fitur AI, dan kamera tidak diuji ulang pada clone itu. Belum diuji di macOS atau Linux (berkas .bat hanya untuk Windows; di sana pakai php artisan serve).
