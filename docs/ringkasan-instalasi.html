Pasang Hormone Growth di Komputer Anda

Dari GitHub sampai bisa dicoba, 6 langkah sekitar 30 menit

Gitambil kode
PHP 8.3+jalankan aplikasi
Composerpasang pustaka
MySQLdatabase
1

Ambil kode

git clone https://github.com/yoezf/Siakad.git
cd Siakad

Repo privat: minta pemilik menambahkan akun GitHub Anda.

2

Pasang pustaka

composer install
3

Siapkan pengaturan

copy .env.example .env
php artisan key:generate
4

Buat database lalu isi .env

CREATE DATABASE sekolah_app CHARACTER SET utf8mb4;
# di .env isi: DB_DATABASE, DB_USERNAME, DB_PASSWORD
# dan ubah:   QUEUE_CONNECTION=sync
5

Isi data contoh

php artisan demo:isi --ya

Menghapus isi database di .env. Pakai database kosong atau uji. Sekitar 1 sampai 2 menit.

6

Jalankan

php artisan serve   # atau klik jalankan-lokal.bat

Buka http://127.0.0.1:8000/sekolah/login

Akun uji, kata sandi: demo-sekolah-2026

Admin SD: admin@harapanbangsa.demo (/sekolah/login)

Orang tua: ortu@harapanbangsa.demo (/portal/login)

Super Admin: super@demo.test (/admin/login)

Panduan lengkap dan solusi masalah ada di PANDUAN-INSTALASI.pdf. Akun demo hanya untuk komputer sendiri, bukan server publik.
